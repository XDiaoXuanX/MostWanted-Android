# Most Wanted for Android v1.4.0 — modded by YBPUT (tidak resmi)

Modifikasi dari [RanggaCasper/MostWanted-Android](https://github.com/RanggaCasper/MostWanted-Android) v1.4.0. Proyek asli berlisensi GPL-3.0; modifikasi ini juga GPL-3.0.
Source lengkap ada di repo ini (fork), perubahan didokumentasikan di folder `junkman-mod/` (skrip patch + dokumentasi).

## Isi
- Pilihan marker setelah mengalahkan Blacklist: 2 -> 6
- Junkman tidak habis setelah dipakai
- Semua kategori Backroom (Performance, Parts, Visual) tampil
- Diuji di Cobalt dan RX-8

## Pasang
1. Hapus instalasi resmi dulu (tanda tangan berbeda). Backup `MostWanted/hdd`.
2. Pasang APK ini.
3. Taruh game milik sendiri di `/storage/emulated/0/MostWanted` (ISO Xbox Black Edition USA atau `default.xbe` + folder `NFS`).

APK ini **tidak berisi aset game**. Kamu harus punya salinan game sendiri.
